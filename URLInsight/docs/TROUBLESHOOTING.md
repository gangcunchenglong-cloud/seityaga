# トラブルシューティング

## 拡張のポップアップに「ネイティブホストに接続できません」と出る

1. URL Insight を起動し、設定 → ブラウザ拡張 →「ホストを登録」を押す。
2. 拡張機能ID が `chrome://extensions` に表示される ID と一致しているか確認する（同梱の拡張をそのまま読み込んだ場合は `jmmabchpljfpflppkhkhbfejbhjaadii`）。違う場合は設定で ID を書き換えて保存し、もう一度「ホストを登録」。
3. 拡張のポップアップで「再接続」を押すか、Chrome を再起動する。
4. `URLInsight.NativeHost.exe` がアプリと同じフォルダにあるか確認する（アプリのフォルダを移動した場合は、アプリ起動時に自動で再登録されます）。

レジストリの確認: `HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts\com.urlinsight.linklens` の既定値が `%LOCALAPPDATA%\URLInsight\native-host\com.urlinsight.linklens.json` を指していれば登録済みです。

## 「URL Insight アプリ: 起動していません」と出る

アプリが起動していないか、終了しています。スタートメニューから URL Insight を起動してください（ネイティブホストはアプリを勝手に起動しません）。常に使う場合は 設定 → 一般 →「Windows起動時に開始」をオンにします。

## ホバーしてもカードが出ない

- そのサイトで拡張を有効にしたか（拡張アイコン →「このサイトで有効にする」）。有効化直後はページの再読み込みが必要な場合があります。
- アプリが「一時停止中」になっていないか。
- そのURLを「無視」にしていないか（設定 → プライバシー → 無視するURL）。
- Chrome の内部ページ（chrome://）、Chrome ウェブストア、PDF ビューアー内などでは拡張が動作しません（ブラウザの仕様）。

## 「AI設定が必要です」と出る

設定 → AI でプロバイダを選び、モデル名と API キーを入力して「キーを保存」→「保存して閉じる」。「接続テスト」で疎通を確認できます（短いテスト文だけを送信します）。キー無しで動作確認したい場合は「テスト用（ローカル・AIではありません）」を選ぶと、本文の冒頭を抜粋したカードが表示されます。

## 「APIキーを確認してください」(401/403)

キーの誤り・失効・権限不足です。提供元の管理画面でキーを確認し、再入力してください。

## 「AIの利用上限に達しました」(429)

提供元の利用枠・レート制限です。時間をおいて再試行するか、モデル/プロバイダを変更してください。`Retry-After` が20秒以内なら自動で1回だけ再試行します。

## 「このページは取得が制限されています」

ログイン必須・CAPTCHA・アクセス拒否(403)のページです。本アプリは Cookie やログイン情報を送らないため取得できません。ページを手動で開いてください。

## 「ローカル/社内ネットワーク宛てのURLは取得しません」

安全のため、localhost・プライベートIP・社内向けホスト名（ドット無し / .local / .internal 等）への取得を拒否しています。

## 社内プロキシ環境で取得できない

ページ取得は接続先 IP を検証するため、システムのプロキシを使わず直接接続します（SSRF 対策を確実にするため）。直接の外部接続が許可されていない環境では、ページ取得ができません（既知の制限）。AI プロバイダへの通信はシステムのプロキシ設定に従います。

## PDF が要約できない

- 「文字を取り出せないPDFです」: スキャン画像の PDF です（OCR は未対応）。
- 「暗号化されたPDFのため対象外です」: パスワード・権限設定付き PDF は処理しません。
- 20MB を超える PDF は取得を中止します。50ページを超える場合は先頭50ページのみを対象にします。

## YouTube の要約が限定的

字幕本文は、公式APIでは動画所有者以外ダウンロードできないため取得しません。設定 → AI で YouTube Data API キーを設定すると、説明欄をもとに要約できます（「説明欄のみで続ける」の確認が出ます）。

## カードの位置がおかしい / 画面外に出る

マルチモニター・DPI 変更直後に起きた場合は、カードを閉じて再度ホバーしてください。表示位置は 設定 → 一般 → 表示位置 で左右を切り替えられます。再現する場合は 設定 → 詳細 →「診断情報を書き出す」の内容とモニター構成を添えて報告してください。

## ログ・診断情報

- ログ: 設定 → 詳細 →「ログの保存先を開く」（`%LOCALAPPDATA%\URLInsight\logs`）
- エラーカードの「エラーID」でログを検索できます。
- 「診断情報を書き出す」は URL のパス・キー・本文を含まないことを自動検査してから保存します。
