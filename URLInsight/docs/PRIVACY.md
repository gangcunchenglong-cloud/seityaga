# プライバシーとデータの扱い

URL Insight は、あなたが理解・制御できる範囲でだけ情報を扱うことを方針としています。**初期状態では AI への送信は一切行いません。** テレメトリ（利用状況の送信）もありません。

## データの流れ

| # | どこから → どこへ | 送る内容 | いつ |
| --- | --- | --- | --- |
| 1 | Chrome拡張 → URL Insight アプリ（同じPC内） | ホバーしたリンクのURL、リンク文字列（最大200字）、表示中ページのタイトル（最大300字）、タブの識別子 | **拡張のポップアップで有効にしたサイト**で、リンクに一定時間（初期600ms）カーソルを合わせたとき |
| 1' | 画面上のリンク → URL Insight アプリ（同じPC内・拡張なしのホバー検出） | カーソル下の要素のリンク先URL・リンク文字列、またはカーソル位置の行の文字列（URLの抽出にだけ使い、保存しない） | 設定「拡張機能なしでもホバーを検出する」がオン（既定）で、カーソルが一定時間止まったとき。自分のウィンドウとパスワード欄は対象外 |
| 2 | アプリ → リンク先サイト | 通常の HTTP(S) GET リクエスト（Cookie・ログイン情報・ブラウザのプロファイルは送らない） | 1 の後、または URL を手動で貼り付けたとき |
| 3 | アプリ → AI 提供元（あなたが選んだもののみ） | ページの URL・タイトル・説明・本文（上限文字数まで。初期12,000字） | AI プロバイダとキーを設定し、**送信前の確認で「送信」を選んだとき**（毎回確認／各プロバイダ初回のみ確認 を選択可） |
| 4 | アプリ → YouTube（公式 oEmbed / Data API） | 動画ID（Data API キーを設定した場合はキーも） | YouTube のリンクを要約するとき |

- 1 は Windows の名前付きパイプ（同じ Windows ユーザーのプロセスのみ接続可）で行い、ネットワークポートは開きません。
- 2 では localhost・社内ネットワーク（プライベートIP）・リンクローカル等への接続を拒否します（SSRF 対策）。

## このPCに保存されるもの

保存場所: `%LOCALAPPDATA%\URLInsight`

| ファイル | 内容 | 保持期間 |
| --- | --- | --- |
| `settings.json` | 設定（APIキーは含まない）、無視するURLの一覧 | 削除するまで |
| `secrets\*.bin` | APIキー（Windows DPAPI・現在のユーザーで暗号化） | 削除するまで |
| `cache.db` | 要約結果・タイトル・URL・ドメイン・作成日時（**ページ本文は保存しない**） | 初期7日 / 最大1000件 / 250MB（設定可） |
| `logs\*.log` | 時刻・処理段階・所要時間・エラーコード等（URL はホスト名まで、本文・キー・プロンプトは記録しない） | 7日 / 合計10MB |
| `native-host\*.json` | Chrome がネイティブホストを見つけるためのマニフェスト | 登録解除まで |

暗号化は、PC への不正アクセスやマルウェアからキーを守るものではありません。

## 削除方法

- 個別: 設定 → キャッシュ・履歴（履歴の個別削除・全消去）、設定 → AI（キーの削除）、設定 → プライバシー（無視リスト）
- 全部: 設定 → 詳細 →「すべてのユーザーデータを削除して終了」
- アンインストール時: 「ユーザーデータも削除しますか？」で「はい」を選択

## AI 提供元について

送信したデータの扱い（学習への利用・保持期間など）は各提供元の規約に従います。費用・無料枠も提供元の条件に従い、本アプリでは保証しません。プロバイダは「未設定」に戻すことでいつでも送信を止められます（設定 → プライバシー →「AIへの送信を無効化」）。

## Chrome 拡張の権限

| 権限 | 理由 |
| --- | --- |
| `nativeMessaging` | PC 上の URL Insight アプリと通信するため |
| `storage` | 有効にしたサイトの一覧・待ち時間などを保存するため |
| `scripting` | 有効にしたサイトにだけリンク検出スクリプトを登録するため |
| `activeTab` | 「このタブだけ一時的に有効にする」ため |
| 任意のホスト権限（`optional_host_permissions`） | サイトごとに、あなたが「有効にする」を押したときだけ要求。`<all_urls>` を常時要求することはありません |
