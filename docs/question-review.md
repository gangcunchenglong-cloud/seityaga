> この点検は、先生が問題を承認（`approved`）する前の**下準備**です。
> 問題の `status` は、すべて `draft`（確認前）のまま変えていません。

## 3. 先生に判断していただきたい問題

正誤に問題はありませんが、**学校の端末やアプリによって画面の言葉や手順が違う**可能性がある問題です。学校の環境に合わない場合は、レビュー用ツールの「編集」で言葉を直すか、「却下」してください。

### PC・Chromebook 向け

| id | 内容 | 注意点 |
|---|---|---|
| `g4-op-pc-07` | デスクトップを右クリックして新しいフォルダーを作る | Windows の操作。Chromebook にはデスクトップの右クリックメニューがない |
| `gp2-op-pc-06` | 右クリックから ZIP 形式に圧縮する | Windows と Chromebook でメニューの言葉が少し違う |
| `g1-op-pc-07` | Ctrl + H で置換の画面を開く | Word・Google ドキュメントでは Ctrl + H。ソフトによって違う |
| `g2-op-pc-09` | Ctrl + U で下線を引く | 多くの文書作成ソフトで共通だが、ソフトによって違うことがある |
| `g4-op-pc-05` / `g4-op-pc-09` | Ctrl + B（太字）／ Ctrl + I（斜体） | 多くの文書作成ソフトで共通 |

## 4. 準1級の難しさについて

準1級（高校生めやす）には、2進数、1バイト＝8ビット、COUNTIF・VLOOKUP、情報セキュリティの三要素、公開鍵暗号、PPDAC サイクルなど、高校「情報Ⅰ」で学ぶ内容を入れています。
高校生にとっては教科書の範囲ですが、**中学生が準1級に挑戦すると、知識がないと解けない問題が多くなります**。中学生が受けることが多い場合は、問題の入れかえを検討してください。

## 5. 承認の進め方（おすすめ）

1. `npm run dev` → `http://localhost:5173/scripts/review.html` を開き、確認者の名前を入力する
2. `src/questions/grade-*.json` を読み込み、1問ずつプレビューで実際に解いて確認する（上の「3.」の問題は特に注意）
3. 「承認」「却下」「編集」を行い、「承認した問題だけ書き出す」
4. `npm run merge -- 書き出したファイル.json` → `npm test` → `npm run build`

各級・各分野で承認済みの問題が3問以上そろうと、その級が本番モードで受験できるようになります。
