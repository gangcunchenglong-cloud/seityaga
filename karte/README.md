# 電子カルテシステム(HTML + JavaScript)

ブラウザだけで動く、シンプルな病院向け電子カルテのサンプルです。
サーバーやインストールは不要で、`index.html` をブラウザで開くだけで使えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 患者管理 | 登録・編集・削除、ID/氏名/フリガナでの検索、年齢の自動計算 |
| 患者情報 | 生年月日、性別、血液型、連絡先、保険者番号、緊急連絡先、アレルギー、既往歴 |
| 診療記録 | SOAP形式(S:主観/O:客観/A:評価/P:計画)、診療科、担当医、傷病名 |
| バイタル | 血圧・脈拍・体温・SpO2・体重を記録し、基準外の値を赤字表示、推移を表で表示 |
| 処方 | 複数薬剤の登録。患者のアレルギーと一致する薬剤名を入力すると警告 |
| 検索 | 診療記録をキーワード・診療科で絞り込み |
| 印刷 | 患者のカルテを印刷用レイアウトで出力 |
| バックアップ | 全データをJSONで書き出し・読み込み |

## ファイル構成

- `index.html` … 画面の構造(患者一覧、詳細、入力ダイアログ)
- `style.css` … デザイン(スマホ表示・印刷用スタイルを含む)
- `app.js` … データ管理と画面描画の処理

## 注意事項

- データはブラウザの `localStorage` に保存されます。ブラウザのデータを消去すると失われるため、
  定期的に「データ書き出し」でバックアップしてください。
- 初回起動時にはサンプル患者が2名登録されます。
- 本システムは学習・デモ用です。実際の医療現場で使うには、ユーザー認証、アクセス権限、
  通信と保存データの暗号化、操作ログ(監査証跡)、サーバー側でのデータ管理など、
  厚生労働省「医療情報システムの安全管理に関するガイドライン」に沿った対策が必要です。
