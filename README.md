# URLビューア

URLを入力すると、ページの中にそのサイトを表示して操作できるツールです。

## 使い方

### すべてのサイトを表示する(プロキシあり・おすすめ)

Node.js 18 以上が必要です(追加のインストールは不要)。

```
node server.js
```

ブラウザで http://localhost:3000/ を開き、URLを入力して「開く」を押します。
中継サーバーがサイトの「埋め込み禁止」設定を取り除くため、Google や X など
通常は埋め込めないサイトも表示できます。右上の「プロキシ」のチェックを外すと、
中継せずに直接表示します。

ポートを変えたい場合は `PORT=8080 node server.js` のように指定します。

### ファイルを直接開く(プロキシなし)

`url-viewer.html` をダブルクリックで開いても使えますが、埋め込みを禁止している
サイトは表示されません。

## 制限事項

- ログイン(特に Google アカウントなど)、動画配信、WebSocket を使うチャットなど、
  一部の機能は正しく動かないことがあります。
- 表示中のサイトの Cookie は localhost にまとめて保存されます。
- 中継サーバーは誰でも使える中継役になるため、既定では自分のPCからの接続だけを
  受け付けます。インターネットに公開しないでください。
